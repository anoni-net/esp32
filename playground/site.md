示範韌體是社群開始做隨身偵測器之前，用來摸清 ESP32-S3 能力的工具。燒進開發板之後，用手機或筆電連上板子的熱點，控制頁會自動跳出來，在網頁上就能操作晶片的各項功能，了解這塊板子實際做得到什麼。工作坊第一次接觸 ESP32 的時候，也可以先燒這一份玩一玩。

## 可以操作的功能

| 區塊 | 內容 |
|---|---|
| 晶片資訊 | 型號、核心與時脈、晶片溫度、flash 與 PSRAM 用量、可用記憶體 |
| RGB LED | 用調色盤控制板上的彩色燈 |
| 觸控腳位 | 即時讀取幾支腳位的電容觸控數值，手指碰到時數字會變 |
| 傳輸速度 | 從板子下載測試資料，算出 Wi-Fi 的速度 |
| Wi-Fi 掃描 | 周圍的基地台、訊號、頻道與加密方式 |
| 藍牙掃描 | 被動掃描 3 秒，列出周圍的藍牙裝置 |
| 運算效能 | 整數與浮點運算、硬體加速的 SHA-256 與 AES、記憶體搬移的速度，以及向量指令的加速效果 |
| 外部 Wi-Fi | 讓板子同時連上家裡的網路，熱點維持開啟 |
| OTA 更新 | 上傳韌體檔、從網址下載，或定期檢查新版 |

手機也可以用藍牙連上板子，在藍牙終端機 App 裡輸入文字指令，不必連 Wi-Fi。連線前要先配對，輸入控制頁上顯示的 6 位數配對碼。

## 安裝

示範韌體是開發用的工具，熱點密碼固定是 `playground`，OTA 更新也沒有驗證簽章，所以沒有放上網頁安裝，只提供用 PlatformIO 自行建置、燒錄的方式：

```bash
git clone https://github.com/anoni-net/esp32.git
cd esp32/playground
pio run -t upload
```

PlatformIO 的安裝與燒錄的細節見[安裝韌體]({root}install/)。

## 對隱私的設計

熱點與連外用的 Wi-Fi 每次開機都換一組隨機的位址，藍牙對外使用定期更換的隨機位址，周圍的人與連上的路由器都沒辦法用固定的位址認出這塊板子。藍牙配網會傳送 Wi-Fi 密碼，所以一定要先配對加密，密碼也不寫進事件紀錄。
