# 圖示

網頁用到的圖示，建置時由 `site/build.py` 的 `icon()` 內嵌進 HTML，不透過字型或 CDN 載入，onion 版一樣可用（同 anoni-net/www 的 `icons/`）。

取自 mkdocs-material 9.7.7 隨附的圖示，跟 anoni-net/www 同一套。只放用到的圖示。

| 檔名 | 來源 | 授權 |
|---|---|---|
| 沒有前綴，例如 `usb.svg` | [Material Design Icons](https://pictogrammers.com/library/mdi/) | Pictogrammers Free License，全文在 [LICENSE-material.txt](./LICENSE-material.txt) |
| `octicons-*.svg` | [Octicons](https://primer.style/octicons/)（GitHub） | MIT，全文在 [LICENSE-octicons.txt](./LICENSE-octicons.txt) |
| `simple-*.svg` | [Simple Icons](https://simpleicons.org/) | CC0 1.0，全文在 [LICENSE-simple-icons.md](./LICENSE-simple-icons.md) |

`simple-torproject.svg` 是 Tor Project 的商標，只用來標示 onion 位址。
